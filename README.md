# 📊 ApexPlanet Data Analytics Internship Project

## Customer Churn Analysis using IBM Telco Customer Churn Dataset

---

## 📌 Overview

This project was completed as part of the **45-Day Data Analytics Internship** conducted by **ApexPlanet Software Pvt. Ltd.**

The project demonstrates a complete end-to-end data analytics workflow using the **IBM Telco Customer Churn Dataset**. It covers data preprocessing, exploratory data analysis, SQL-based business analysis, interactive dashboard development, statistical analysis, customer segmentation, predictive modeling, and automation.

The objective of this project is to transform raw customer data into meaningful business insights that support data-driven decision-making and customer retention strategies.

---

# 🎯 Project Objectives

* Build a structured data analytics environment.
* Clean and preprocess raw customer data.
* Perform Exploratory Data Analysis (EDA).
* Analyze customer behavior using SQL.
* Develop an interactive Power BI dashboard.
* Perform statistical analysis and time-series forecasting.
* Segment customers using K-Means Clustering.
* Build machine learning models for prediction.
* Automate the analytics workflow.
* Present business recommendations based on analytical findings.

# 📈 Key Findings

* Customers with Month-to-Month contracts have the highest churn rate.
* Higher Monthly Charges are associated with increased customer churn.
* Long-term customers are more likely to remain with the company.
* Fiber Optic customers exhibit comparatively higher churn.
* Electronic Check is the most common payment method among churned customers.
* Customer tenure is one of the strongest indicators of customer loyalty.
* Customer segmentation identified distinct customer groups for targeted retention strategies.

# 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-link>
```

### 2. Navigate to the Project Folder

```bash
cd apexplanet-data-analytics
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Notebooks

Execute the notebooks in the following order:

1. Task1_EDA.ipynb
2. Task2_SQL.ipynb
3. Task3_Visualization.ipynb
4. Task4_Statistical_Modeling.ipynb

### 5. Run the Automation Pipeline

```bash
python scripts/automation_pipeline.py
```
