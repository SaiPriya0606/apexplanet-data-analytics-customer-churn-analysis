# Task 4 – Advanced Analytics & Statistical Modeling

## Dataset
IBM Telco Customer Churn Dataset

## Objective
Perform statistical analysis, time series forecasting, customer segmentation, and predictive modeling using machine learning techniques.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Statsmodels
- Matplotlib
- Seaborn
- Joblib

---

## Time Series Analysis

- Created a monthly time-series using average monthly charges by tenure.
- Performed seasonal decomposition.
- Conducted the Augmented Dickey-Fuller (ADF) stationarity test.
- Applied moving average smoothing.
- Applied exponential smoothing.
- Built an ARIMA forecasting model.
- Evaluated forecasting using MAE and RMSE.

---

## Customer Segmentation

- Standardized numerical features.
- Applied K-Means clustering.
- Determined the optimal number of clusters using the Elbow Method.
- Evaluated clustering quality using the Silhouette Score.
- Visualized customer segments using PCA.
