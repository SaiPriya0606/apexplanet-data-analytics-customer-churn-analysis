# Task 2 - SQL & Data Extraction

## Dataset
IBM Telco Customer Churn Dataset

## Objective
To perform SQL-based data extraction and business analysis by integrating SQLite with Python.

## Tools Used
- Python
- SQLite
- SQLAlchemy
- Pandas
- Jupyter Notebook

## SQL Concepts Covered
- SELECT
- WHERE
- ORDER BY
- LIMIT
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- MIN
- MAX
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER, RANK, LAG, LEAD)
- Parameterized Queries
- Query Optimization using EXPLAIN
- Index Creation

## Business Insights
- Total number of churned customers identified.
- Average monthly charges calculated by contract type.
- Most commonly used payment methods identified.
- Customer distribution across internet service types analyzed.
- Top customers with highest monthly charges identified.
